# Python Data Exploration & Preparation

## Overview

This folder contains the Python notebooks used to inspect and prepare the [UCI Online Retail dataset](https://archive.ics.uci.edu/dataset/352/online+retail) for the **E-commerce Sales Intelligence** project.

Using Python, Pandas, and Jupyter Notebook, the analysis examines data quality, investigates unusual transactions, and prepares intermediate datasets for further analysis in Google BigQuery.

## Notebooks

### 1. [Raw Data Inspection](01_Raw_Data_Inspection.ipynb)

Examines the original transaction data, including its structure, missing values, duplicates, quantity and price distributions, cancellation invoices, and unusual records. Preliminary calculations are exploratory and do not represent the final dashboard KPIs.

### 2. [Data Cleaning](02_Data_Cleaning.ipynb)

Documents the preparation decisions informed by the initial inspection. It removes exact duplicates, investigates zero-price and operational records, reviews unusually large invoices without customer identifiers, distinguishes cancellation invoices, and produces four intermediate datasets.

The approach is deliberately selective: an unusual transaction is not automatically an invalid transaction.

## Running the Notebooks

1. Download the source workbook from the [UCI Online Retail dataset page](https://archive.ics.uci.edu/dataset/352/online+retail) and save it as `02_Data/Raw/Online_Retail.xlsx` within the project folder.
2. Use a Python environment with `pandas`, `openpyxl`, and Jupyter support. For example, install the packages with `pip install pandas openpyxl notebook`.
3. Open the project in VS Code or Jupyter and run `01_Raw_Data_Inspection.ipynb`, followed by `02_Data_Cleaning.ipynb`.

Both notebooks locate the source workbook relative to common project working directories rather than relying on a computer-specific Windows path. The cleaning notebook writes its generated files to `02_Data/Processed/`.

## Prepared Datasets

| Generated file | Description |
|---|---|
| `df_clean.csv` | Transaction data after removing exact duplicate rows |
| `df_sales.csv` | Prepared data after selected sales-related exclusions |
| `df_orders.csv` | Prepared data excluding cancellation invoices |
| `df_revenue.csv` | Positive-quantity transactions with a calculated `Revenue` column |

The CSVs are generated locally and excluded from the public repository because of their size. They can be regenerated by running the data-cleaning notebook with the source workbook in place.
